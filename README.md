## Oque é o projeto?

Sistema de gestão de laboratórios e ativos composto por uma aplicação web, um aplicativo mobile e uma API integrada, permitindo o cadastro de laboratórios e equipamentos, consulta por QR Code, registro de movimentações e visualização do histórico dos ativos. O MVP deverá demonstrar um fluxo funcional completo, oferecendo maior organização, rastreabilidade e confiabilidade na gestão dos equipamentos.
